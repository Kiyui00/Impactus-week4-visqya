# Impactus Week 4 - React

Project Week 4 yang dibuat menggunakan React JS dan Vite.

## Cara Menjalankan Project

1. Clone repository ke komputer.
2. Buka terminal pada folder project.
3. Install dependencies dengan perintah:

   ```bash
   npm install

Jalankan development server dengan perintah:
npm run dev

Lalu buka alamat yang ditampilkan di terminal
